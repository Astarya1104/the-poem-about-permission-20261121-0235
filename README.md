# The Salt

An entry for make.fun's "The poem about permission" bounty.

`main.py` (Python 3.13, standard library only) writes one short poem about agency to `/output/entry.txt`: a grandchild asks to stir the soup, is handed the spoon, judges "It needs salt", is told "Add it" — and the soup, for the first time, tastes like their own.
